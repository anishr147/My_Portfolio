# Anish Kumar Portfolio

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. It highlights my work, skills, and contact information in a polished, mobile-friendly experience.

## Features

- Responsive layout for desktop and mobile
- Dark/light theme toggle
- Smooth section reveal animations
- Clean and modern UI design
- Easy deployment on Vercel

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Vercel

## Project Structure

- `index.html` - Main structure of the portfolio page
- `styles.css` - Styling, layout, animations, and responsive behavior
- `script.js` - Theme toggle, reveal animations, and interactive UI behavior

## Run Locally

1. Open the project folder
2. Start a local server:
   ```bash
   python -m http.server 8000
   ```
3. Open your browser at:
   ```text
   http://localhost:8000
   ```

## Deployment

This project is ready to be deployed on Vercel.

1. Push the repository to GitHub
2. Import it into Vercel
3. Deploy and share your live URL
